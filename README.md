# 投票日和（とうひょうびより）

全国の選挙日程・選挙区・定数・候補者をまとめた選挙情報サイトのプロトタイプです。
ビルド不要の静的サイトなので、GitHub Pages・Cloudflare Pages・Vercel などにそのまま置けます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面（トップ、検索、選挙ページ、候補者ページ、掲載プラン、陣営の編集画面） |
| `data.js` | 選挙データ。毎日の自動更新はこのファイルだけを書き換えます |
| `scripts/check.mjs` | データ確認。`node scripts/check.mjs` で全ページを描画してエラーがないか確認します |
| `.nojekyll` | GitHub Pages でそのまま配信するための空ファイル |

## data.js の形式

- `RAW`（2026年分）：1行1選挙 `投票日YYYY-MM-DD|告示日MM-DD|選挙名|都道府県`
- `RAW2`（2027年以降）：
  - 日付確定：`YYYY-MM-DD|YYYY-MM-DD(告示日)|選挙名|都道府県`
  - 見込み：末尾に `|見込み`
  - 時期のみ：`YYYY-MM|~8〜9月ごろ|選挙名|都道府県`
- `EX`：選挙名ごとの補足 `{seats: 定数, note: 補足, src: 出典}`
- `DIST`：定数・選挙区・候補者。すべての選挙で使えます。
  - 選挙区が1つの選挙（首長選、市区町村議選）は `list` を `全域|市区町村名|定数` の1行にする
  - `cands['選挙区名'] = {src: 出典, off: 1(告示後の正式な候補者のとき), c: 氏名|年齢|党派|現職/元職/新人|備考 を1行ずつ}`
- `FEAT`：トップの「注目の選挙」
- `UPDATED`：最終更新日（YYYY-MM-DD）

## GitHub Pages での公開手順

1. GitHub で新しいリポジトリ（例：`tohyobiyori`）を作り、このフォルダの中身をすべてアップロードする
2. リポジトリの Settings → Pages → Build and deployment で「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 1〜2分後に `https://<ユーザー名>.github.io/tohyobiyori/` で公開されます
4. 独自ドメインを使う場合は同じ画面の Custom domain に設定します

## 毎日の自動更新

Claude の定期実行タスクが毎朝、選挙管理委員会・報道などを調べて `data.js` を更新し、
`node scripts/check.mjs` で確認してからリポジトリにコミットします。コミットされると GitHub Pages に自動で反映されます。

## 掲載ルール

- 優先する情報源：選挙管理委員会、総務省、官報、新聞・テレビ、政党の公式発表
- 選挙ドットコム（go2senkyo.com）の文章・写真・プロフィールは取り込まない
- 推測で日付・人名・年齢を入れない。出典を必ず記載する
- 「あおば県」の選挙と候補者 c1〜c9 は画面の見本用の架空データ

## 公開前に確認が必要なこと

- 選挙期間中の有料掲載が公職選挙法上どう扱われるか（選挙運動用の有料ネット広告の禁止など）は、選挙法に詳しい弁護士への確認が必要です
- 料金表は仮の金額です。会員登録・決済・陣営ログインは画面のみで、実際には動きません
