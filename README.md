# 投票日和（とうひょうびより）

全国の選挙日程・選挙区・定数・候補者をまとめた選挙情報サイトのプロトタイプです。
ビルド不要の静的サイトなので、GitHub Pages・Cloudflare Pages・Vercel などにそのまま置けます。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `index.html` | 画面（トップ、検索、選挙ページ、候補者ページ、掲載プラン、陣営の編集画面） |
| `data.js` | 選挙データ。毎日の自動更新はこのファイルだけを書き換えます |
| `votes.json` | 得票数・開票速報。投票日の夜はこのファイルを更新します |
| `scripts/build.mjs` | 選挙ごとの静的ページ作成。`node scripts/build.mjs` で `senkyo/`（選挙ごとのページと一覧）と `sitemap.xml` を作り直します。data.js や index.html を変えたら実行してから commit します |
| `senkyo/` | build.mjs が作るページ。選挙ごと（`/senkyo/投票年/選挙名/`）、都道府県ごと（`/senkyo/熊本県/`）、市区町村ごと（`/senkyo/熊本県/苓北町/`）と全国一覧。検索エンジン向け。手で編集しない。index.html の `<!--pref-links-->` の間も build.mjs が書き直す |
| `og.png` | SNS で共有されたときに表示される画像 |
| `scripts/check.mjs` | データ確認。`node scripts/check.mjs` で全ページを描画してエラーがないか確認します |
| `.nojekyll` | GitHub Pages でそのまま配信するための空ファイル |

## data.js の形式

- `RAW`（2026年分）：1行1選挙 `投票日YYYY-MM-DD|告示日MM-DD|選挙名|都道府県`
- `RAW2`（2027年以降）：
  - 日付確定：`YYYY-MM-DD|YYYY-MM-DD(告示日)|選挙名|都道府県`
  - 見込み：末尾に `|見込み`
  - 時期のみ：`YYYY-MM|~8〜9月ごろ|選挙名|都道府県`
- `EX`：選挙名ごとの補足 `{seats: 定数, note: 補足, src: 出典}`
- `DIST`：定数・選挙区・候補者。すべての選挙で使えます。
  - 選挙区が1つの選挙（首長選、市区町村議選）は `list` を `全域|市区町村名|定数` の1行にする
  - `cands['選挙区名'] = {src: 出典, off: 1(告示後の正式な候補者のとき), c: 氏名|年齢|党派|現職/元職/新人|備考 を1行ずつ}`
  - 開票速報：候補者行の末尾に `|得票数|当`（当選者）または `|得票数|`。備考が空でも列は省かない（例 `山田太郎|50|無所属|新人||1234|当`、得票数不明の当選者は `山田太郎|50|無所属|新人|||当`）。選挙区に `res:{st:'速報'|'確定', at:'YYYY-MM-DD HH:MM', rate, turnout, src}` を付けると、選挙ページの得票表示と、トップの「開票結果」（投票日から7日間）に出ます。votes.json に同じ選挙区があればそちらを優先します
- `DIST[選挙名].prev`：前回の結果（任意）。選挙ページの「前回の結果」に表示します。
  - `{date:'前回の投票日YYYY-MM-DD', turnout:'投票率', voters:'有権者数', note:'短い説明（無投票など）', src:'出典（媒体名・記事名・日付）', c:`氏名|年齢|党派|新現元|得票数|当` を1行ずつ}`
  - 得票数がわからない・無投票のときは得票数欄を空にする。当選者だけ末尾に `当`。選挙区が複数ある選挙は c を省き、turnout と note だけでよい
  - 数字・氏名は選挙管理委員会の発表か報道で確認できたものだけ。選挙ドットコム（go2senkyo.com）からは取り込まない
- `FEAT`：トップの「注目の選挙」
- `UPDATED`：最終更新日（YYYY-MM-DD）

## votes.json（得票数・開票速報）

候補者名の横に得票数を表示します。投票日の当日と翌日は、選挙ページを開いている間60秒ごとに `votes.json` を読み直し、数字が変わればその場で表示を更新します。

```json
{
  "updated": "2026-12-13T22:30:00+09:00",
  "elections": {
    "茨城県議会議員選挙": {
      "date": "2026-12-13",
      "dist": {
        "石岡市": {
          "status": "counting",
          "at": "2026-12-13T22:30:00+09:00",
          "rate": "62%",
          "src": "茨城県選挙管理委員会 開票速報",
          "v": { "氏名（data.jsと同じ表記）": 12345 },
          "win": ["当選確実・当選の氏名"]
        }
      }
    }
  }
}
```

- キーは `data.js` の選挙名（`DIST` と同じ）と選挙区名。選挙区が1つの選挙は `全域`
- `status`：`counting`（開票速報。当選者は「当選確実」と表示）／`final`（確定。「当選」と表示）
- 数字のない候補者は「得票 —」と表示します
- GitHub Pages の配信キャッシュがあるため、コミットから画面に出るまで数分かかることがあります

## GitHub Pages での公開手順

1. GitHub で新しいリポジトリ（例：`tohyobiyori`）を作り、このフォルダの中身をすべてアップロードする
2. リポジトリの Settings → Pages → Build and deployment で「Deploy from a branch」、Branch を `main` / `(root)` にして Save
3. 1〜2分後に `https://<ユーザー名>.github.io/tohyobiyori/` で公開されます
4. 独自ドメインを使う場合は同じ画面の Custom domain に設定します

## 毎日の自動更新

Claude の定期実行タスクが毎朝、選挙管理委員会・報道などを調べて `data.js` を更新し、
`node scripts/check.mjs` で確認してからリポジトリにコミットします。コミットされると GitHub Pages に自動で反映されます。

## 掲載ルール

- 優先する情報源：選挙管理委員会、総務省、官報、新聞・テレビ、政党の公式発表
- 選挙ドットコム（go2senkyo.com）の文章・写真・プロフィールは取り込まない
- 推測で日付・人名・年齢を入れない。出典を必ず記載する
- 架空の選挙・候補者（見本データ）は掲載しない。すべて実在の選挙のみ

## 陣営プラン（有料掲載）

料金：初期費用 25,000円（税込27,500円）＋区分ごとの月額。最低利用期間1年・自動更新。

| 区分 | 月額（税抜） | 税込 |
| --- | --- | --- |
| 国政 | 11,300円 | 12,430円 |
| 首長・都道府県議会・政令市議会 | 9,000円 | 9,900円 |
| 東京23区・中核市の議会 | 6,000円 | 6,600円 |
| 一般市議会 | 4,800円 | 5,280円 |
| 町村議会 | 3,300円 | 3,630円 |

料金は index.html の `INIT`（初期費用・税抜）と `TIERS`（区分・月額税抜）で変えられます。

画面：`#plans`（料金）→ `#apply`（申込フォーム）→ カード決済 または 請求書。`#terms`（利用規約）、`#tokusho`（特定商取引法に基づく表記）。

### 受付を始める手順（index.html の `SALES` を書き換える）

1. **申込の受付先**：Formspree などのフォーム受付サービスでフォームを作り、その URL を `form` に入れる（申込内容が運営のメールに届きます）。使わない場合は `mail` に運営のメールアドレスを入れると、申込者のメールアプリに申込内容が下書きされます
2. **カード決済**：Stripe で区分ごとに「支払いリンク」を作り、`stripe` の各区分に URL を入れる
   - 商品は2つ入れる：初期費用 27,500円（1回払い）と月額（毎月の継続支払い）
   - 支払いリンクには申込番号（`client_reference_id`）とメールアドレスが自動で付くので、Stripe の管理画面で申込と照合できます
   - URL が空の区分は、カード払いを選べず請求書払いだけになります
3. **請求書払い**：本人確認後、初期費用＋12か月分の請求書を送る（freee・Misoca・Stripe Invoicing など）
4. **特定商取引法の表記**：`seller` に事業者名・責任者・所在地・電話・メールを入れる
5. 弁護士の確認が済んだら `open: true` にして、`node scripts/build.mjs` → commit

掲載は今まで通り data.js で行います。入金と本人確認が済んだ候補者は、`plan:'pre'` にすると陣営プランの表示になります。

## 公開前に確認が必要なこと

- 選挙期間中の有料掲載が公職選挙法上どう扱われるか（公職選挙法142条の6：選挙運動期間中の選挙運動用有料インターネット広告の禁止など）は、選挙法に詳しい弁護士への確認が必要です。規約では暫定的に「告示日から投票日までは新規申込と内容変更を停止」としています
- 利用規約・特定商取引法の表記は雛形です。受付開始前に弁護士に確認してもらってください
- 陣営ログイン（陣営が自分で編集する画面）は画面のみで、実際には保存されません。当面は原稿をメールで受け取り、運営が data.js に反映します
