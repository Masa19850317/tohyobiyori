# 受付サーバー（Google Apps Script）

サイトのフォーム（陣営ページの編集・陣営プランの申込・無料会員登録）の送信先です。
写真付きで受け取り、契約済みの陣営は本人のメール確認だけで自動公開します。

## 流れ

```
陣営が「保存して送信」
  └→ 受付サーバー：スプレッドシート「投票日和 受付」に記録、写真は Drive「投票日和 陣営写真」へ
       ├ 契約済み（「契約」シートに氏名とメールが一致）
       │    └→ 陣営の登録メールに確認リンク → 陣営が「公開する」 → jin.js と img/ を GitHub にコミット → 数分で公開
       ├ はじめての陣営・メールが登録と違う
       │    └→ 運営に「承認して公開」リンク → 入金・本人確認のあと運営が押す → 公開＋「契約」シートに登録
       └ 告示日〜投票日（jin.js の elect の選挙）
            └→ 保留。運営にお知らせ（利用規約どおり）
```

- 公開のたびに運営（ADMIN_MAIL）にもメールが届きます。GitHub にはコミットが残るので、戻したいときは revert できます
- 政策は「1. 見出し」の行から次の空行までを1項目、番号のない文はメッセージとして読みます。活動実績の【SNS】の下の「名前 URL」行は SNS ボタンになります
- 略歴（career）・ふりがな・選挙・契約期間は運営が承認画面で入れたものを保ち、陣営の原稿では上書きしません
- フリープランの原稿は自動公開せず、運営にメールで届きます（data.js に手で反映）

## 設置（はじめに1回・15分ほど）

1. **GitHub のトークンを作る**
   GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token
   - Repository access：Only select repositories → `tohyobiyori`
   - Permissions：Contents を **Read and write**（ほかは不要）
   - 期限は1年など。作ったトークン（github_pat_…）を控える
2. **Apps Script を作る**
   https://script.google.com → 新しいプロジェクト → 名前「投票日和 受付」
   - `Code.gs` の中身をすべて消して、このフォルダの `Code.gs` を貼り付けて保存
   - 左の歯車（プロジェクトの設定）→ 一番下「スクリプト プロパティ」に追加
     - `GH_TOKEN`：手順1のトークン
     - `ADMIN_MAIL`：通知を受け取るメール（例 mob.record23@gmail.com）
3. **setup を実行**
   エディタ上部の関数で `setup` を選び「実行」→ Google の権限を許可（「詳細」→「安全ではないページに移動」→ 許可。自分で作ったスクリプトなので問題ありません）
   実行ログに「GitHub: OK」とスプレッドシートの URL が出れば成功です
   スプレッドシートの「契約」シートの井上耕兵さんの行に、申込メールのアドレスと電話番号を入れてください（このリポジトリは公開なので、コードには書いていません）
4. **ウェブアプリとしてデプロイ**
   右上「デプロイ」→「新しいデプロイ」→ 種類「ウェブアプリ」
   - 次のユーザーとして実行：**自分**
   - アクセスできるユーザー：**全員**
   - デプロイ → 表示された「ウェブアプリの URL」（https://script.google.com/macros/s/…/exec）を控える
5. **サイトにつなぐ**
   index.html の `SALES` の `form:''` に手順4の URL を入れて commit（Claude に URL を渡せば反映します）

`Code.gs` を直したときは「デプロイを管理」→ 鉛筆 → バージョン「新バージョン」で更新します（URL は変わりません）。

## 確認

`node apps-script/test.mjs` で、原稿の解析・jin.js の書き換え・告示期間の判定を確かめられます。
